# FMRCoreV3/Config.gs — alpha.23 version patch

In the Core Apps Script project, open `Config.gs`.

Replace:

```javascript
VERSION: '3.0.0-alpha.22',
```

with:

```javascript
VERSION: '3.0.0-alpha.23',
```

Do not change `DEFAULT_DATABASE_ID`, sheet names, headers, or database
configuration in this release.
